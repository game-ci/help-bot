## Bot Response (downvoted)
This is a Docker environment difference causing assembly resolution issues. Your buildProfile parameter is correctly configured.

Try these solutions:
• Add `customParameters: '-nographics -logFile -'` to match your working terminal command
• Set `targetPlatform` explicitly (e.g., `targetPlatform: WebGL`)
• Ensure your Unity version in the build profile matches GameCI's available versions
• Consider using `buildMethod` instead of buildProfile if Naninovel assemblies need special handling
• Check that pre-compiled DLLs are included in your repo and not gitignored

The issue occurs because containerized Unity installations may resolve assembly paths differently than local installations. See https://game.ci/docs/github/getting-started for more configuration options.
