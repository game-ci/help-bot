## Agent Guidance

All agent behavior is defined in `CLAUDE.md`. Refer to that file for the rules, tone, response workflow, and operational guidance (incremental vs live modes, vector search opt-in, secure Discord tokens, Windows NSSM service setup, and supported LLM providers). Do not add independent instructions elsewhere in the repository.

When a prompt needs to mention agent-specific capabilities (Discord/GitHub/docs), link back to `CLAUDE.md` for the authoritative text and examples.
